# Cat Key Quest

Клавіатурна аркада про кота Маркіза: бийся з босами, ухиляйся від пострілів і збирай спорядження.

## Як грати

- Натисни `Enter` або `Пробіл`, щоб почати. Стеж за літерами, що падають у центральне кільце.
- Натискай відповідну клавішу саме тоді, коли літера потрапляє в кільце: влучання знімає здоров’я боса й збільшує комбо.
- Використовуй фізичну клавіатуру: гра розпізнає позицію клавіші, тому англійська літера спрацює і з українською чи російською розкладкою.
- Якщо літера пролетить повз кільце, Маркіз втратить здоров’я. Неправильне натискання лише підкаже правильний порядок.
- З кожним рівнем літери падають швидше, а вікно влучання стає вужчим.
- Після перемог витрачай монети у крамниці: натисни `F4`, тоді номер предмета (`1`–`6`), щоб придбати його. Крамниця призупиняє бій; `Escape` повертає до нього.
- Кожне натискання клавіші супроводжується м’яким звуком; його можна вимкнути кнопкою **Звуки**.
- Після кожної перемоги вибери одну з трьох нагород клавішею `1`, `2` або `3`.
- Броня зменшує отриману шкоду, бластер підсилює атаки, а інші предмети відновлюють здоров’я або збільшують кільце влучання.
- Пройди п’ять рівнів і переможи фінального боса — Короля Котів.
- `Escape` відкриває або закриває крамницю під час бою, `F2` — голосовий ввід, `F3` — озвучення. Звуки перемикаються кнопкою **Звуки**.
- Екранна клавіатура лише показує розташування клавіш; для бою натискай клавіші на фізичній клавіатурі.

## Як запустити

1. Відкрий папку проєкту в VS Code.
2. Запусти локальний HTTP-сервер:

   ```powershell
   python -m http.server 8000
   ```
   
3. Відкрий у браузері адресу http://localhost:8000

Якщо браузер не підтримує голосовий ввід, грай звичайною клавіатурою.
